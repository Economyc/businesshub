Activar el bot de Telegram de BusinessHub

El código ya está listo. Solo faltan estos pasos para encenderlo.
Cada paso dice quién lo hace: TÚ o CLAUDE (la sesión de Claude Code).

1 Crear el bot en Telegram Tú · 3 min

Telegram regala los bots — esto no cuesta nada. Se crea hablándole a un bot oficial llamado BotFather:

  1. Abre Telegram (celular o computador) y busca @BotFather (tiene chulo azul de verificado).
  2. Escríbele: /newbot
  3. Te pregunta el nombre del bot (el que se ve en el chat). Ejemplo: BusinessHub
  4. Te pregunta el username (debe terminar en bot y estar libre). Ejemplo: businesshub_seb_bot
  5. BotFather te responde con un mensaje que incluye el token: una clave larga tipo
    123456789:AAHfK9x2... — ese token es la llave del bot, cópialo.
⚠️ El token es como una contraseña: no lo publiques ni lo subas a GitHub. Solo pásaselo a Claude en el chat o úsalo en el comando del paso 2.

Opcional pero recomendado, ahí mismo en BotFather:

  1. /setjoingroups → elige tu bot → Disable (para que nadie lo meta a grupos).
2 Entregar el token Tú · 1 min

Opción fácil (recomendada): pega el token en el chat de Claude Code y dile "este es el token del bot". Claude hace todo el resto (pasos 3 y 4) automáticamente.

Opción manual: si prefieres hacerlo tú, guarda el token como secreto en Google Cloud:

echo -n "AQUI_VA_EL_TOKEN" | gcloud secrets create TELEGRAM_BOT_TOKEN --data-file=- --project=empresas-bf
✅ El otro secreto que se necesita (TELEGRAM_WEBHOOK_SECRET) ya quedó creado — no tienes que hacer nada con él.
3 Publicar las funciones Claude · 5 min

Esto sube el bot a la nube de Google (gratis para tu volumen de uso). Lo hace Claude, pero por si algún día lo necesitas a mano, son estos dos comandos desde la carpeta functions/:

npm run build gcloud functions deploy telegramBot \ --gen2 --project=empresas-bf --region=us-central1 \ --runtime=nodejs20 --source=. --entry-point=telegramBot \ --trigger-http --allow-unauthenticated \ --memory=512Mi --timeout=300s --max-instances=1 --concurrency=1 \ --set-secrets="TELEGRAM_BOT_TOKEN=TELEGRAM_BOT_TOKEN:latest,TELEGRAM_WEBHOOK_SECRET=TELEGRAM_WEBHOOK_SECRET:latest,GEMINI_API_KEY=GEMINI_API_KEY:latest,CEREBRAS_API_KEY=CEREBRAS_API_KEY:latest,LANGFUSE_PUBLIC_KEY=LANGFUSE_PUBLIC_KEY:latest,LANGFUSE_SECRET_KEY=LANGFUSE_SECRET_KEY:latest,LANGFUSE_BASE_URL=LANGFUSE_BASE_URL:latest,DRIVE_OAUTH_CLIENT_ID=DRIVE_OAUTH_CLIENT_ID:latest,DRIVE_OAUTH_CLIENT_SECRET=DRIVE_OAUTH_CLIENT_SECRET:latest" gcloud functions deploy telegramLinkStart \ --gen2 --project=empresas-bf --region=us-central1 \ --runtime=nodejs20 --source=. --entry-point=telegramLinkStart \ --trigger-http --allow-unauthenticated \ --memory=256Mi --timeout=15s \ --set-secrets="TELEGRAM_BOT_TOKEN=TELEGRAM_BOT_TOKEN:latest"
4 Conectar Telegram con la nube (webhook) Claude · 1 min

Es decirle a Telegram: "cuando alguien le escriba a mi bot, avísale a esta dirección". Un solo comando, una sola vez:

curl -X POST "https://api.telegram.org/bot<TOKEN>/setWebhook" \ -d "url=https://telegrambot-xfyucmyk7q-uc.a.run.app" \ -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>" \ -d 'allowed_updates=["message","callback_query"]' \ -d "drop_pending_updates=true"

La URL exacta sale del deploy del paso 3; el secret se consulta con
gcloud secrets versions access latest --secret=TELEGRAM_WEBHOOK_SECRET --project=empresas-bf

5 Vincular tu cuenta Tú · 1 min

El bot es privado: solo responde a cuentas vinculadas. Para vincular la tuya:

  1. Entra a BusinessHub (businesshub.myvnc.com) → Ajustes → Compañías.
  2. Verás una tarjeta nueva que dice Telegram. Dale clic a "Conectar Telegram".
  3. Se abre Telegram con tu bot y un botón INICIAR (o START). Dale clic.
  4. El bot te responde "Cuenta vinculada ✅" con la lista de tus empresas. ¡Listo!
⏱️ El enlace de vinculación dura 15 minutos y sirve una sola vez. Si se vence, genera otro con el mismo botón.
6 ¡A usarlo! Tú

Háblale al bot como le hablarías a un asistente. Ejemplos reales:

Tú: ¿Cuánto tengo vencido en Blue Manila?

Bot: Tienes 3 facturas vencidas por $2.450.000: …

Tú: Crea una cuenta por cobrar de 350 mil a Distribuidora Norte en Filipo

Bot: 💰 Crear cuenta por cobrar en Filipo — Monto: $350.000 … [✅ Confirmar] [❌ Cancelar]

Tocas ✅ y queda creada en Firestore. Nada se guarda sin tu confirmación.

Tú: 📸 (mandas la foto de una factura con el texto "monta esta factura en Blue Manila")

Bot: 🧾 Crear factura (CxP) en Blue Manila — Proveedor: … N°: … Monto: … Archivo: adjunto → se sube a Drive [✅ Confirmar]

💡 Todo el flujo cuesta $0/mes para tu volumen: el Bot API de Telegram es gratis, las Cloud Functions están dentro de la capa gratuita de Google y el bot usa los mismos modelos gratuitos (Gemini Flash) del agente de la web.
